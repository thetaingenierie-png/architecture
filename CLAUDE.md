# Theta Ingénierie — architecture et béton armé

Compte Claude : thetaingenierie@gmail.com.

Utiliser les connecteurs du dépôt avant de répondre sur un logiciel Autodesk ou un modèle :

- `autodesk-product-help` pour la documentation à jour (Revit Structure, ferraillage, AutoCAD, Robot, Navisworks, Civil 3D).
- `ifc` pour les métrés d'un fichier IFC : poteaux, poutres, voiles, dalles, matériaux, quantités.
- `autocad` pour les plans DXF. Sur ce dépôt le mode est `ezdxf`, sans AutoCAD ouvert.
- `rhino` pour une maquette 3D `.3dm` : géométrie, volumes, nomenclature. Sans Rhino installé, rester en mode fichier.
- `blender` pour une scène Blender. Sans Blender ouvert, ne pas inventer une vue du modèle.
- `sketchup` pour une maquette SketchUp. Sans SketchUp ouvert, ne pas inventer le modèle.
- `autodesk-fusion-data` seulement si un compte Autodesk Fusion est déjà autorisé.

Le ferraillage en direct dans Revit se fait sur le poste Windows, avec Revit 2027.2 ouvert et le connecteur officiel installé par `scripts/install.py`.
